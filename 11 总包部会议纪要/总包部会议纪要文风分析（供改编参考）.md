# 总包部（工程总承包事业部）会议纪要文风分析与写作规范

> 基于"11 总包部会议纪要"目录中 104 份会议纪要（2019—2026年）的全面研读提炼。
> 文件来源：黄河勘测规划设计研究院有限公司 工程总承包事业部 内网发布系统。

---

## 一、文件类型概览

104 份会议纪要可分为三大类：

| 类型 | 数量 | 特点 |
|------|------|------|
| **办公会会议纪要**（周/次编号） | ~80份 | 每周一次的例行办公会，涵盖多项目、多议题，格式固定 |
| **专题会会议纪要** | ~20份 | 针对单一项目或专项议题，内容更聚焦 |
| **项目推进会/评审会** | ~4份 | 特定项目的重要节点会议 |

## 二、格式模板

### （一）办公会会议纪要（2024年起标准格式，占绝大多数）

```
【会议类别】办公会          【会议时间】20XX年X月X日
【会议地点】211会议室        【主 持 人】哈 佳
【参加人员】XXX、XXX、XXX、
            XXX、XXX、黄丽坤
【纪要内容】

1.由XXX副主任负责：
（1）……。责任部门:工程管理部。
（2）……。责任部门:合同采购部。
2.由XXX副主任负责：
（1）……。责任部门:综合管理部。
3.同意XXXXX项目XXX采购。（审批事项列举）
4.同意XXXXX项目立项及班子任命。
5.同意XXXXX事项。
6.同意XXXXX事项。
7.同意XXXXX事项。
```

**关键格式特征：**
- 每条以**"由XXX负责"**开头（明确到人）
- 每条末尾标注**"责任部门：XXX"**
- 审批事项以**"同意"**开头，逐条列举
- 无参会人员结尾、无抄送格式（纯纪要正文）

### （二）专题会会议纪要（正式公文格式，带红头编号）

```
〔20XX〕X号
工程总承包事业部综合管理部              签发人:哈佳

会议类别：专题会
会议议题：XXXXXX
会议时间：20XX年X月X日（上/下）午
会议地点：总包部211会议室
主 持 人：哈佳
参加人员：XXX、XXX、XXX
纪要内容：
20XX年X月X日，工程总承包事业部主任哈佳组织召开XXXX专题会。
……（背景说明）。形成纪要如下：

1、……。
2、……。
   （1）……
   （2）……

发送：事业部各部门、各项目部
整理：XXX
```

### （三）2026年起的新格式变化

2026年起部分办公会开始使用**编号制**：
```
黑河黄藏寺水利枢纽工程专题会
会议纪要
——2026年【GCGLB-HZS-00X】
```

## 三、用词特点

### （一）办公会高频固定句式

**任务分派句式（核心模式）：**
> "由**XX副主任**负责：（1）**紧盯/加强/抓紧/抓好/组织/推进**……工作。**责任部门：XX部**。"

**动词使用频率排序：**
1. **抓好/抓实/抓紧** — "抓好布哈拉、龙岩、黄藏寺等重点总承包项目生产工作"
2. **加强** — "加强内外部沟通""加强统筹协调""加强人才培养管理"
3. **紧盯** — "紧盯黄藏寺项目现场工作进度""紧盯堵水施工进度"
4. **组织** — "组织研究""组织编制""组织修订""组织梳理"
5. **推进/加快推进** — "加快推进海南东方项目收尾""稳步推进龙岩项目TBM施工"
6. **确保** — "确保各项目高质高效履约""确保年度目标的实现"
7. **落实** — "落实……措施""压实各方责任"
8. **梳理** — "梳理项目催款情况""全面梳理总包合同内的工作"
9. **谋划** — "谋划电力施工二级资质的申报事宜"
10. **千方百计** — "千方百计加强款项催要""千方百计确保项目如期到款"

### （二）审批事项固定句式

> "**同意**XXXXX项目XXX服务采购；"
> "**同意**XXXXX项目立项及班子任命；"
> "**原则同意**XXXXX方案，经分管领导审核把关后发布实施。"

### （三）专题会/推进会用语（更丰富、更有动员性）

**动员鼓劲类：**
- "统一思想、群策群力，共同推进"
- "同心协力、互相补位、互相支持"
- "以项目进度为主线，彻底扭转被动局面"
- "工作状态要立即转入决战状态"
- "务必提高站位"

**管理要求类：**
- "事事有人管、件件能落实"
- "不折不扣执行各项工作部署"
- "倒排工期""精准、动态调整"
- "前后方须高效沟通，紧密配合，形成合力"
- "做到款项应收尽收"

**作风建设类（2019-2021年纪要特色）：**
- "以身作则、严格自律、身先士卒"
- "切勿高高在上、颐指气使"
- "把工作当成高尚的事业做起来，而非当成低级的生意敷衍了事"
- "切实提高责任心""对任何工作都要有一种敬畏感"

## 四、逻辑习惯

### （一）办公会行文逻辑（高度固定）

```
1. 党务/综合事务（由副书记负责）— 排第一
2. 设计管理事务（由分管设计副主任负责）
3. 工程管理事务（由分管工程副主任负责）— 内容最多
4. 合同经营事务（由分管合同副主任负责）
5. 监理业务事务（由分管监理的领导负责）
6. 审批事项（"同意……"逐条列举）
7. 其他事项（奖励方案、聘用人员等）
```

**每条内部结构：**
```
由[姓名]+[职务]负责：
  （序号）[动词]+[工作内容]，[时间要求/质量要求]。
  责任部门：[部门名称]。
```

### （二）专题会行文逻辑

```
1. 背景段：时间+主持人+会议目的+传达精神
   → "会议传达了……讲话精神""按照……目标要求"
2. 认识段：阐述重要性、统一思想
   → "各部门通力协作""统一思想、群策群力"
3. 措施段：编号列出具体任务（1、2、3…）
   → 每条含目标+路径+责任
4. 保障段：安全底线、作风建设
   → "严守安全底线""严格遵守建设程序"
```

### （三）时间跨度对比

| 时期 | 文风演变 |
|------|----------|
| **2019-2021** | 篇幅较长、语言更口语化、作风建设内容多（"切勿高高在上""颐指气使"） |
| **2022-2023** | 过渡期，格式趋于规范 |
| **2024-2026** | 高度模板化、每条必标"责任部门"、审批事项标准化、语言精炼 |

## 五、与"06 会议纪要"的文风对比

| 维度 | 06目录（黄委/黑河局/设计院） | 11目录（总包部） |
|------|------|------|
| **政治站位** | 高（大量引用习近平总书记/李国英部长批示） | 较低（偶尔传达上级精神） |
| **文体庄重度** | 规范公文体（红头文件、抄送、印发） | 内部工作纪要（简洁实用） |
| **语言风格** | 四字短语密集、排比对仗 | 简明直白、动词驱动 |
| **篇幅** | 长篇（每份1000-3000字） | 短篇（每份500-1500字） |
| **核心关注** | 安全、除险、应急处置 | 生产进度、催款、采购审批 |
| **任务分配** | 按单位（"EPC总承包单位要……"） | 按个人（"由XX副主任负责"） |
| **结尾** | 参会人员+抄送+印发 | 直接结束（办公会）/ "发送：各部门"+整理人（专题会） |

## 六、改编录音逐字稿时的关键原则

### 1. 确定文件类型
- **例行办公会** → 用办公会模板（【】括号格式 + 编号任务 + 审批事项）
- **专题会** → 用专题会模板（红头编号 + 表头信息 + "形成纪要如下"）

### 2. 任务分派标准化
- 录音中"这个事情让老黄去弄" → "由黄培杰副主任负责：（1）……。责任部门：工程管理部。"
- 每条任务必须包含：**负责人 + 动词 + 工作内容 + 责任部门**

### 3. 审批事项归纳
- 讨论中通过的事项 → 单独编号，以"同意"开头逐条列举
- 项目立项、班子任命、采购审批等归类列出

### 4. 用词规范对照表

| 口语/非规范 | 总包部规范用语 |
|------------|-------------|
| 去催一下款 | 紧抓欠款催收，抓好"归仓行动"的落实 |
| 把进度搞快点 | 紧盯施工进度，加快推进…… |
| 跟XX对接一下 | 加强与XX的沟通对接/沟通协调 |
| 这个事谁来管 | 由XX负责，责任部门：XX部 |
| 看看行不行 | 组织研究/论证……的可行性 |
| 钱的事 | 催款工作/到款目标/产值结算 |
| 搞个方案 | 组织编制/编制切实可行的方案 |
| 别出安全事故 | 严守安全底线/确保安全生产 |
| 大家一起弄 | 统筹协调/通力协作/形成合力 |
| 尽快弄完 | 抓紧推进/确保如期完成 |

### 5. 专题会过渡语
- 开头：`"20XX年X月X日，工程总承包事业部主任哈佳组织召开XXXX专题会。……形成纪要如下："`
- 传达精神：`"会议传达了……讲话精神""按照……目标要求"`

### 6. 部门分工常识
改编时需要了解总包部的部门职能：
- **综合管理部** → 党建、人事、考核、宣传、劳动纪律、资质申报
- **工程管理部** → 施工组织、安全管理、项目进度、现场协调
- **设计管理部** → 设计方案、技术支持、设计变更
- **合同采购部** → 招标采购、合同管理、催款、成本测算
- **监理公司** → 监理项目业务
- **费控中心** → 费用审核、造价控制
