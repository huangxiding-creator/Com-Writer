# 总包部（工程总承包事业部）通知文风分析与写作规范

> 基于"12 总包部通知"目录中 669 份通知（2017—2026年）的全面研读提炼。
> 文件来源：黄河勘测规划设计研究院有限公司 工程总承包事业部 内网发布系统。

---

## 一、通知类型分类

669 份通知可归纳为以下七大类：

| 类型 | 典型标题模式 | 数量占比 | 特点 |
|------|------------|----------|------|
| **安全生产类** | "关于做好XX期间安全生产工作的通知""关于加强XX安全生产管理工作的通知" | ~30% | 数量最多，节日/季节/特殊时期全覆盖 |
| **会议活动类** | "关于召开XX会议的通知""关于开展XX活动的通知" | ~20% | 会议通知格式固定，活动通知含主题/时间/地点/参加人员 |
| **人事任免类** | "关于XX同志职务任命/任免的通知" | ~10% | 党委文件格式，极简 |
| **考核评优类** | "关于开展XX年度考核工作的通知""关于XX评选结果的通知" | ~10% | 含考核依据、对象、标准 |
| **计划报送类** | "关于报送XX年度XX计划的通知""关于报送XX的通知" | ~10% | 简洁，强调截止时间 |
| **制度规范类** | "关于进一步规范/加强XX的通知""关于明确XX的通知" | ~10% | 政策性最强、篇幅最长 |
| **转发类** | "转发关于XX的通知" | ~10% | 简短转述+附加要求 |

## 二、格式模板

### （一）标准通知格式（最常用）

```
各部门、各项目部：

（背景说明1-2句）。现将有关事项通知如下：

一、（主题标题）
（具体内容）

二、（主题标题）
（具体内容）

……

联系人：XXX
电话：XXXXXXX

附件：XXX


                              工程总承包事业部
                               20XX年X月X日

附件：XXX.xxx
```

### （二）会议通知格式

```
各部门、各项目部：

（会议背景）。经（总包部/事业部）研究，定于X月X日召开XXXX会议。
现将有关事项通知如下：

一、会议时间及地点
20XX年X月X日（星期X），会期X天。
上午X:XX-X:XX；下午X:XX-X:XX。
地点：XXX会议室。

二、参会人员
（列出参会人员范围）

三、会议主要内容/会议议题
1、……
2、……

四、有关要求
1、请各部门合理安排工作，按时参会。
2、……

联系人：XXX  电话：XXXX
```

### （三）人事任免通知格式

```
黄设党〔20XX〕XX号

关于XX等X位同志职务任命/任免的通知

公司各部门、各单位党组织：

根据工作需要，经公司党委/事业部研究决定：

任命XX同志为XXXXX；
免去XX同志XXXXX职务。

特此通知。


                    中共黄河勘测规划设计有限公司委员会
                              20XX年X月X日
```

### （四）转发通知格式

```
各部门、各项目部：

现将公司/黄委《关于XXXX的通知》转发给你们，并结合总包部实际，
提出如下要求，请一并贯彻执行：

一、……
二、……

                              工程总承包事业部
                               20XX年X月X日
```

## 三、用词特点

### （一）开头固定句式

| 场景 | 固定句式 |
|------|---------|
| **节日安全** | "20XX年XX节将至，为确保……现将……通知如下：" |
| **工作部署** | "根据公司《XX》要求/精神，结合总包部实际，现将……通知如下：" |
| **会议召开** | "经总包部研究/事业部研究，定于X月X日召开XX会议。现将有关事项通知如下：" |
| **转发** | "现将公司/黄委《关于XX的通知》转发给你们，……请认真贯彻执行。" |
| **活动开展** | "为……（目的），总包部决定开展……活动。具体事宜通知如下：" |
| **报送材料** | "根据……要求，现开展……工作，请各项目部……于X月X日前报送。" |

### （二）高频管理用语

**安全类（出现频率最高）：**
- "提高政治站位，强化安全生产责任落实"
- "牢固树立'安全第一'理念""时刻绷紧安全驾驶/安全生产这根弦"
- "全面夯实""逐级传导""不打折扣"
- "把隐患当做事故处理""消除在萌芽状态"
- "从'要我安全'到'我要安全'的转变"
- "杜绝盲目赶工""杜绝违规用车""杜绝公车私用"

**管理要求类：**
- "高度重视""认真做好""切实做好""务必"
- "严格自律""以身作则""严格履行"
- "抓紧抓实""做实做细""落细落实"
- "举一反三""全面梳理""全面排查"
- "建立台账""动态管理""闭环管理"

**廉政纪律类：**
- "深入落实中央八项规定及其实施细则精神"
- "营造风清气正节日氛围"
- "严禁收送……严禁违规发放……严禁大操大办……严禁公款吃喝……"
- "发现一起，查处一起，通报一起"
- "持续释放越往后执纪越严的强烈信号"

**时间要求类：**
- "于X月X日前报送"
- "逾期不予受理"
- "请按时提交"
- "即日起至X月X日"

### （三）通知结尾固定要素

```
联系人：XXX
电话：XXXXXXX（或内线XXXXX）

附件：XXX


                    工程总承包事业部（或 综合管理部 / 纪委 等）

```

### （四）称谓规范

| 通知对象 | 规范写法 |
|----------|---------|
| 全体发布 | "各部门、各项目部：" |
| 仅项目部 | "各项目部：" 或 "各EPC项目部：" |
| 仅部门 | "各部门：" |
| 安全类 | "总包部各项目（部门）：" 或 "事业部各项目（部门）：" |
| 党组织 | "公司各部门、各单位党组织：" |

## 四、逻辑习惯

### （一）整体行文逻辑

```
1. 称谓（各部门、各项目部：）
2. 背景说明（为什么发通知）— 1-2句
3. 过渡语（"现将有关事项通知如下："）
4. 正文（按"一、二、三…"分条）
   每条 = 小标题 + 具体要求
5. 联系人/电话
6. 附件列表
7. 落款（发文单位 + 日期）
```

### （二）安全生产通知的固定逻辑链

```
一、提高政治站位，落实安全职责
    → 引习近平总书记重要论述 → 强调政治站位 → 要求逐级落实责任
二、提升安全意识，强化教育培训
    → 针对特定时期风险 → 组织培训交底 → 杜绝麻痹思想
三、做好风险研判，加强隐患排查
    → 紧盯重点场所/部位/环节 → 全面排查 → 闭环整改
四、严格值班值守，提升应急处置
    → 领导带班制度 → 应急准备 → 信息报告
```

### （三）会议通知的固定逻辑链

```
背景（为什么开会）→ 会议时间地点 → 参会人员 → 会议内容/议题 → 有关要求
```

### （四）活动通知的固定逻辑链

```
目的意义（1段抒情/动员）→ 活动主题 → 征集/活动时间 → 参加人员 →
作品要求/活动内容 → 评选/奖励办法 → 报送方式及截止时间
```

## 五、通知与会议纪要的文风对比

| 维度 | 会议纪要（11目录） | 通知（12目录） |
|------|-------------------|---------------|
| **人称** | 第三人称（"由XX负责"） | 第二人称（"各部门/各项目部"）|
| **语气** | 记录性的（"同意……"） | 指令性的（"请……""严禁……"）|
| **时效** | 事后（记录已开会议） | 事前（部署将要开展的工作）|
| **结构** | 任务分条 + 审批列举 | 背景说明 + 分条要求 |
| **落款** | 无落款（办公会）/ 发送+整理（专题会）| 发文单位 + 日期 |
| **篇幅** | 500-1500字 | 200-1500字（安全类偏长）|

## 六、改编录音逐字稿为通知的关键原则

### 1. 确定通知类型
- **部署工作** → 标准通知格式（背景+分条要求+联系人+落款）
- **召开会议** → 会议通知格式（时间地点+参会人员+议题+要求）
- **开展活动** → 活动通知格式（主题+时间+要求+评选办法）
- **转发上级文件** → 转发格式（转述+附加要求）
- **人事任免** → 人事格式（"任命XX为……特此通知。"）

### 2. 称谓选择
- 总包部内部通用：`"各部门、各项目部："`
- 仅涉及现场：`"各项目部："`
- 安全专题：`"总包部各项目（部门）："`

### 3. 开头写法
- 每份通知必须有**1-2句背景说明**（为什么发这个通知）
- 紧接**"现将有关事项通知如下："**或**"现将……通知如下："**

### 4. 分条编号
- 大条用**中文数字**（一、二、三…），每条有小标题
- 小条用**阿拉伯数字**（1、2、3…）

### 5. 结尾必备要素
- 联系人+电话
- 附件（如有）
- **落款**：`工程总承包事业部` + 日期
- 日期用**中文大写**：`二〇二四年十二月三十一日`（早期）或 `2024年12月31日`（近期）

### 6. 用词规范对照表

| 口语/非规范 | 通知规范用语 |
|------------|------------|
| 大家注意一下 | 请各部门/各项目部高度重视 |
| 把这个事情做了 | 请于X月X日前完成/报送 |
| 别忘了 | 务必/切勿/严禁 |
| 赶紧弄 | 抓紧组织/加快推进 |
| 出了事要追责 | 对XX行为将按相关规定严肃处理/追责问责 |
| 必须参加 | 请按时参会/原则上不得请假 |
| 按时交 | 于X月X日前报送，逾期不予受理 |
| 节日期间注意安全 | 切实做好XX节日期间安全生产工作 |
| 不要违规 | 严禁……（逐条列举禁止事项）|

### 7. 安全生产通知"四段式"（最常用的固定模板）
```
一、提高政治站位，落实安全职责
二、提升安全意识，强化教育培训
三、开展隐患排查，做好风险管控
四、严格值班值守，提升应急处置
```
这四段几乎每份安全通知都出现，措辞高度一致，改编时可直接套用。
